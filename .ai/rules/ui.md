# Ui

## Use white dropdown surfaces
Shared select, dropdown-menu, and navigation-menu surfaces use a white background with dark text to keep all application dropdowns readable and visually consistent.

## Use high-contrast dropdown interaction states
Closed select and navigation-menu triggers use white surfaces with dark text. Hovered or keyboard-highlighted dropdown options use black backgrounds with white text.
