# Development Priorities

Implement in approximately this order:

1. Authentication.
2. Employee and Administrator / Approver roles.
3. Database schema and Eloquent relationships.
4. Leave type management.
5. Employee leave request CRUD.
6. Server-side authorization.
7. Administrator approval/rejection workflow.
8. Validation.
9. Search/filtering.
10. Status and interaction polish.
11. Seed/test accounts and representative sample data.
12. Automated tests for critical rules.
13. Production build.
14. Deployment.
15. Optional enhancements.

When there is a choice between adding a new feature and fixing reliability/security in an existing required feature, fix the required feature first.
